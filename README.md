# 目标守护（MVP）

一个隐私优先的 Chrome / Edge 浏览器插件原型：用户先设定目标，插件只在小红书和抖音网页版的推荐流中发现持续、明显无关的浏览时提醒用户。

## 已实现

- 当前目标设置：目标类型、模糊目标、细化、完成时间、自由浏览豁免。
- 小红书与抖音网页首次目标提示。
- 本地规则检测：推荐流 + 每 30 秒页面可见文字采样 + 连续 5 分钟无关键词匹配。
- `回到目标`、`继续浏览`、`不是分心` 三种反馈，以及可手动关闭的专注浮层。
- 本地反馈冷却：不会保存触发页面、标题、URL 或浏览记录。
- 清除全部本地数据。

## 隐私承诺

- 不发送任何网络请求，不接入模型或统计服务。
- 页面可见文字仅在内容脚本内存中短暂参与匹配；不写入浏览器存储。
- 浏览器存储只包含用户主动填写的当前目标、目标类型、提醒冷却和无内容反馈次数。
- 插件只申请小红书、抖音两个站点和本地存储权限。

## 本地加载

1. 在 Chrome 或 Edge 打开扩展管理页面。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本项目文件夹。
5. 点击浏览器工具栏中的“目标守护”，设置一个非自由浏览目标，再进入小红书或抖音网页版测试。

## 测试

在项目目录运行：

```powershell
node tests/matching.test.js
```

## 当前限制

- 网站页面结构和文案会变化；推荐流识别目前使用轻量页面特征，后续应为两个站点各自补充更可靠的选择器。
- 相关性判断是关键词匹配，不是语义理解；“油痘肌夏季护肤流程”这类间接相关内容可能被误报。
- “不是分心”的学习仅调整当前目标的提醒频率，不建立兴趣画像。
